# Changelog

See [CHANGELOG.md](https://github.com/wiederin/go-invoicer/blob/main/CHANGELOG.md) in the repository root.

## v0.3.0

Document kinds (quotes, credit notes, receipts), branding partials with line-column toggles, settlement report rendering, and expanded examples/docs.

## v0.2.0

Modern/Studio templates, localization (en/de/fr), Stripe sync client, platform render API, Swiss QRR validation.

## v0.1.0

Initial public release: invoice domain, HTML/PDF rendering, Swiss QR-bill, Stripe webhook parser, examples, and docs.
